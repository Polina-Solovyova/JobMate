# 🚀 JobMate — персональный Telegram-ассистент для поиска вакансий

[![Python Version](https://img.shields.io/badge/python-3.11%2B-blue)](https://www.python.org/)
[![License: AGPL v3](https://img.shields.io/badge/License-AGPL_v3-blue)](https://www.gnu.org/licenses/agpl-3.0)
[![Telegram Bot API](https://img.shields.io/badge/Telegram%20Bot%20API-20.x-brightgreen)](https://core.telegram.org/bots/api)
[![Telethon](https://img.shields.io/badge/Telethon-1.34-blueviolet)](https://docs.telethon.dev/)

**JobMate** — Telegram-ассистент для автоматического поиска вакансий в Telegram-каналах.

Пользователь подключает свой Telegram-аккаунт, добавляет каналы, на которые он имеет доступ, создаёт собственные фильтры, а JobMate отслеживает новые публикации и отправляет уведомления только о подходящих вакансиях.

Каждый пользователь работает со своей Telegram-сессией, каналами, фильтрами и историей обработанных постов. Данные разных пользователей изолированы друг от друга.

## 🌟 Возможности

### 👥 Многопользовательский режим

JobMate рассчитан на работу с несколькими пользователями.

Для каждого пользователя отдельно хранятся:

* Telegram-сессия;
* список отслеживаемых каналов;
* фильтры вакансий;
* обработанные посты;
* состояние мониторинга каналов.

Один пользователь не получает данные и уведомления другого пользователя.

### 🔐 Подключение личного Telegram-аккаунта

Telegram-аккаунт подключается непосредственно через бота:

1. пользователь запускает `/connect`;
2. вводит номер телефона;
3. получает код Telegram;
4. вводит код в боте;
5. при включённой двухфакторной аутентификации вводит пароль 2FA;
6. после успешной авторизации JobMate сохраняет Telethon-сессию.

Интерактивный ввод номера, кода или пароля в консоли не используется.

### 📢 Мониторинг Telegram-каналов

Пользователь самостоятельно добавляет каналы, которые его Telegram-аккаунт может просматривать.

JobMate:

* проверяет доступ к каналу;
* сохраняет канал в MongoDB;
* периодически проверяет новые публикации;
* не обрабатывает один и тот же пост повторно;
* позволяет включать и отключать мониторинг отдельных каналов.

### 🎯 Фильтры вакансий

Можно создавать фильтры на естественном языке.

Примеры:

```text
UX/UI дизайнер удалённо, без опыта
```

```text
Python разработчик, но не junior
```

```text
Project Manager OR Product Manager, remote
```

Фильтры поддерживают:

* обязательные условия;
* желательные условия;
* исключающие условия;
* локацию;
* опыт;
* включение и отключение фильтра;
* редактирование;
* удаление.

### 🧠 Сопоставление вакансий

Для сопоставления используются:

* нормализация текста;
* обработка словоформ;
* синонимы;
* точное совпадение;
* совпадение по токенам;
* ограниченный fuzzy matching;
* обязательные и исключающие условия;
* расчёт итогового score.

### 📊 Оценка релевантности

Каждая подходящая вакансия получает оценку соответствия фильтру.

При обработке учитываются обязательные, желательные и исключающие условия.

### 🔔 Персональные уведомления

Уведомления отправляются непосредственно пользователю Telegram.

В уведомлении может содержаться:

* название канала;
* текст вакансии;
* подходящие фильтры;
* ссылка на исходный пост.

Общий `NOTIFICATION_CHAT_ID` для всех пользователей не используется.

## 🏗 Архитектура

JobMate состоит из Telegram Bot API, отдельных пользовательских Telethon-клиентов, MongoDB и модулей обработки вакансий.

```text
                         TELEGRAM
                            │
              ┌─────────────┴─────────────┐
              │                           │
       Telegram Bot API            Telegram User API
      python-telegram-bot              Telethon
              │                           │
              │                    ┌──────┴──────┐
              │                    │             │
              │                User #1       User #2
              │                session       session
              │                    │             │
              │                    └──────┬──────┘
              │                           │
              └─────────────┬─────────────┘
                            │
                         MongoDB
                            │
              ┌─────────────┼─────────────┐
              │             │             │
            Users        Channels       Filters
              │             │             │
              └─────────────┼─────────────┘
                            │
                          Posts
                            │
                            ▼
                  Vacancy Processing
                            │
              ┌─────────────┴─────────────┐
              │                           │
       Vacancy Detection              Matching
              │                           │
              └─────────────┬─────────────┘
                            │
                          Score
                            │
                            ▼
                      Notifications
```

### Telegram Bot API

`python-telegram-bot` отвечает за:

* команды;
* inline-кнопки;
* пользовательский интерфейс;
* авторизацию через `/connect`;
* отправку уведомлений.

### Telegram User Client

`Telethon` работает от имени Telegram-аккаунта конкретного пользователя.

Он используется для:

* авторизации пользовательского аккаунта;
* доступа к каналам;
* чтения новых публикаций;
* мониторинга каналов.

Для каждого пользователя создаётся отдельная сессия.

### Telegram Client Manager

`telegram_clients.py` управляет активными Telethon-клиентами:

* создаёт клиент для пользователя;
* переиспользует существующую сессию;
* запускает polling;
* останавливает polling;
* завершает все пользовательские клиенты при остановке приложения.

### MongoDB

MongoDB хранит:

* пользователей;
* пользовательские каналы;
* фильтры;
* обработанные посты.

Ключевые пользовательские данные имеют `user_id`, поэтому операции выполняются в контексте конкретного пользователя.

## 📦 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/Polina-Solovyova/JobMate.git
cd JobMate
```

### 2. Создание виртуального окружения

Linux/macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Windows:

```bash
python -m venv .venv
.venv\Scripts\activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка `.env`

Создайте файл `.env` в корне проекта.

```env
BOT_TOKEN=ваш_токен_бота

MONGO_URI=mongodb+srv://user:password@cluster.mongodb.net/

TELEGRAM_API_ID=ваш_api_id
TELEGRAM_API_HASH=ваш_api_hash

TELEGRAM_SESSION_NAME=user_session

MONGO_DB_NAME=jobmate
```

### Переменные окружения

| Переменная              | Назначение                  |
| ----------------------- | --------------------------- |
| `BOT_TOKEN`             | токен Telegram-бота         |
| `MONGO_URI`             | строка подключения MongoDB  |
| `TELEGRAM_API_ID`       | Telegram API ID             |
| `TELEGRAM_API_HASH`     | Telegram API Hash           |
| `TELEGRAM_SESSION_NAME` | базовое имя Telethon-сессии |
| `MONGO_DB_NAME`         | название базы MongoDB       |

`OWNER_USER_ID` больше не используется.

`NOTIFICATION_CHAT_ID` больше не используется.

### 5. Запуск

```bash
python main.py
```

После запуска бот начинает принимать сообщения.

## 🔑 Получение Telegram API ID и API Hash

Для Telethon необходимы `TELEGRAM_API_ID` и `TELEGRAM_API_HASH`.

1. Откройте [my.telegram.org](https://my.telegram.org/).
2. Авторизуйтесь под своим Telegram-аккаунтом.
3. Откройте **API development tools**.
4. Создайте приложение.
5. Скопируйте `api_id` и `api_hash`.
6. Добавьте их в `.env`.

## 🔐 Подключение Telegram-аккаунта

После запуска:

```text
/connect
```

Бот попросит номер телефона.

```text
+371XXXXXXXX
```

После этого Telegram отправит код подтверждения.

Введите код в чате с ботом.

Если на аккаунте включена двухфакторная аутентификация, бот запросит пароль 2FA.

После успешной авторизации Telethon-сессия сохраняется на сервере.

При следующих запусках повторная авторизация не требуется, если сохранённая сессия действительна.

### Важное ограничение

Telethon-сессия предоставляет доступ к Telegram-аккаунту пользователя. Файлы сессий являются чувствительными данными и должны храниться в защищённом месте.

Файлы сессий нельзя добавлять в Git.

## 🧠 Обработка вакансий

После появления нового поста JobMate выполняет несколько этапов.

### 1. Получение нового поста

Telethon получает новые сообщения из отслеживаемого канала.

Для каждого пользователя используется собственное состояние `last_message_id`.

Это позволяет продолжать мониторинг с последнего успешно обработанного сообщения.

### 2. Защита от повторной обработки

Каждый пост сохраняется в MongoDB с привязкой к:

```text
user_id
channel_id
message_id
```

Таким образом один и тот же пост может быть обработан отдельно для разных пользователей, но не обрабатывается повторно для одного пользователя.

### 3. Определение вакансии

`vacancies.py` анализирует текст публикации.

Используются:

* признаки вакансий;
* признаки найма;
* признаки трудоустройства;
* стоп-слова;
* информация о зарплате;
* контактные данные;
* другие текстовые признаки.

### 4. Извлечение данных

Из текста могут извлекаться:

* название должности;
* зарплата;
* локация;
* опыт;
* навыки;
* контактные данные.

### 5. Сопоставление с фильтрами

`matching.py` проверяет вакансию относительно активных фильтров пользователя.

Поддерживаются:

* обязательные условия;
* желательные условия;
* исключающие условия;
* синонимы;
* словоформы;
* fuzzy matching.

### 6. Расчёт score

Результат сопоставления содержит оценку релевантности:

```text
score
```

а также информацию о совпавших и отсутствующих условиях.

### 7. Уведомление

Если вакансия соответствует активному фильтру, пользователь получает уведомление непосредственно в Telegram.

## 🧪 Тестирование

Для ручной проверки рекомендуется использовать собственный тестовый Telegram-канал.

### Проверка авторизации

1. Запустите бота.
2. Выполните `/connect`.
3. Введите номер телефона.
4. Введите код Telegram.
5. При необходимости введите пароль 2FA.
6. Убедитесь, что авторизация завершилась успешно.

### Проверка каналов

1. Откройте «Мои каналы».
2. Добавьте тестовый канал.
3. Убедитесь, что канал появился в списке.
4. Отключите мониторинг.
5. Включите мониторинг снова.
6. Удалите канал.

### Проверка фильтров

1. Создайте фильтр.
2. Добавьте обязательное условие.
3. Добавьте исключающее условие.
4. Проверьте редактирование.
5. Проверьте включение и отключение.
6. Проверьте удаление.

### Проверка вакансий

Опубликуйте в тестовом канале пост, соответствующий фильтру, и проверьте получение уведомления.

Также проверьте:

* пост, который не является вакансией;
* вакансию без обязательного условия;
* вакансию с исключающим условием;
* повторную обработку одного поста.

## 🐛 Возможные проблемы

| Проблема                                 | Возможное решение                                                       |
| ---------------------------------------- | ----------------------------------------------------------------------- |
| `BOT_TOKEN is not configured`            | Проверьте `BOT_TOKEN` в `.env`.                                         |
| `MONGO_URI is not configured`            | Проверьте строку подключения MongoDB.                                   |
| Telethon не авторизуется                 | Проверьте `TELEGRAM_API_ID` и `TELEGRAM_API_HASH`.                      |
| Сессия Telethon перестала работать       | Удалите соответствующий файл сессии и выполните `/connect` повторно.    |

| Не приходят уведомления                  | Проверьте активность канала и фильтра, а также логи приложения.         |
| После перезапуска мониторинг не работает | Проверьте наличие и сохранность файлов Telethon-сессий.                 |
| MongoDB не создаёт индексы               | Проверьте доступ приложения к базе данных и права пользователя MongoDB. |

## 🔒 Безопасность

JobMate работает с пользовательскими Telegram-сессиями. Это требует особого внимания к безопасности.

### Не храните в MongoDB

Не следует сохранять в MongoDB:

* номер телефона;
* код подтверждения Telegram;
* пароль двухфакторной аутентификации.

Эти данные используются только во время процесса авторизации.

### Защищайте session-файлы

Telethon session-файл предоставляет авторизованный доступ к Telegram-аккаунту.

Поэтому:

* не публикуйте session-файлы;
* не добавляйте их в Git;
* не отправляйте их в публичные issue;
* ограничьте права доступа к каталогу `sessions/`.

В `.gitignore` должны находиться:

```gitignore
.env
sessions/
*.session
*.session-journal
__pycache__/
*.pyc
```

### Изоляция пользователей

Запросы к пользовательским каналам и фильтрам выполняются с учётом `user_id`.

Посты также имеют пользовательскую область:

```text
user_id + channel_id + message_id
```

Это позволяет нескольким пользователям одновременно отслеживать один и тот же Telegram-канал независимо друг от друга.

Если вы нашли ошибку или хотите предложить улучшение:

1. создайте Issue;
2. опишите проблему или предлагаемое изменение;
3. при необходимости создайте Pull Request.

Перед Pull Request рекомендуется проверить:

* работу авторизации;
* работу каналов;
* работу фильтров;
* обработку новых постов;
* отсутствие утечек пользовательских данных;
* отсутствие session-файлов в Git.
