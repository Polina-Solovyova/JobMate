# 🚀 JobMate — Персональный Telegram-ассистент для поиска вакансий

[![Python Version](https://img.shields.io/badge/python-3.11%2B-blue)](https://python.org)
[![License: AGPL v3](https://img.shields.io/badge/License-AGPL_v3-blue)](https://www.gnu.org/licenses/agpl-3.0)
[![Telegram Bot API](https://img.shields.io/badge/Telegram%20Bot%20API-v20.5-brightgreen)](https://core.telegram.org/bots/api)
[![Telethon](https://img.shields.io/badge/Telethon-v1.34-blueviolet)](https://docs.telethon.dev)

**JobMate** — это ваш личный помощник, который отслеживает выбранные Telegram-каналы, определяет вакансии, анализирует их по вашим фильтрам и присылает только подходящие предложения. Бот использует **ваш собственный Telegram-аккаунт** для чтения каналов, поэтому работает с любыми каналами, на которые вы подписаны.

## 🌟 Возможности

- 🔍 **Мониторинг любых каналов** — вы добавляете каналы, на которые подписаны, и бот читает новые посты через ваш аккаунт.
- 🎯 **Умные фильтры** — создавайте поисковые запросы на естественном языке (например, *«UX/UI дизайнер удалённо, без опыта»*). Бот сам разобьёт их на обязательные, желательные и исключающие условия.
- 🧠 **Продвинутое сопоставление** — поддерживает синонимы, лемматизацию (русский язык), нечёткий поиск (fuzzy), учёт словоформ.
- 📊 **Рейтинг релевантности** — каждая вакансия получает оценку в процентах, вы можете настроить порог уведомлений.
- 📱 **Красивые карточки вакансий** — структурированное отображение с кнопками для перехода к исходному посту и в канал.
- ⏸ **Гибкое управление** — включайте/отключайте отслеживание каналов и фильтров в один клик.
- 🗂 **Полный контроль** — вы сами добавляете и удаляете каналы, создаёте и редактируете фильтры.

## 🏗 Архитектура

Проект построен на **двух Telegram-клиентах**:

```
                    TELEGRAM
                       │
            ┌──────────┴──────────┐
            │                     │
     Telegram User Client      Telegram Bot
        (Telethon)           (python-telegram-bot)
            │                     │
      читает каналы          интерфейс и UI
            │                     │
            └──────────┬──────────┘
                       │
                       ▼
                    MongoDB
                       │
                       ▼
              Vacancy Processing
              ┌────────┴────────┐
              │                 │
       Vacancy Detection      Matching
                                │
                           Scoring
                                │
                                ▼
                         Notifications
```

- **Telegram User Client (Telethon)** — авторизуется под вашим личным аккаунтом, имеет доступ к вашим подпискам, периодически опрашивает добавленные каналы на наличие новых постов.
- **Telegram Bot API (python-telegram-bot)** — предоставляет интерфейс для управления (команды, кнопки, настройки) и отправляет уведомления.
- **MongoDB** — хранит пользователей, каналы, фильтры и посты.
- **Модуль обработки** — определяет, является ли пост вакансией, извлекает структурированные данные, сопоставляет с фильтрами и вычисляет рейтинг.

## 📦 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/yourusername/jobmate.git
cd jobmate
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Настройка переменных окружения

Создайте файл `.env` в корне проекта и заполните его:

```env
# Telegram Bot Token (получить у @BotFather)
BOT_TOKEN=ваш_токен_бота

# MongoDB URI (например, от MongoDB Atlas)
MONGO_URI=mongodb+srv://user:pass@cluster.mongodb.net/dbname

# Данные для Telethon (получить на my.telegram.org)
TELEGRAM_API_ID=ваш_api_id
TELEGRAM_API_HASH=ваш_api_hash
SESSION_NAME=my_session   # имя файла сессии (необязательно)

# ID пользователя, который владеет ботом (ваш Telegram ID)
# Если не указать, клиент Telethon запустится при первом обращении
OWNER_USER_ID=ваш_telegram_id
```

**Как получить `TELEGRAM_API_ID` и `TELEGRAM_API_HASH`:**
1. Перейдите на [my.telegram.org](https://my.telegram.org) и войдите под своим номером.
2. Перейдите в раздел **API development tools**.
3. Создайте новое приложение (укажите название, платформу Desktop, описание от 40 символов).
4. Скопируйте полученные `api_id` и `api_hash`.

**Как узнать свой `OWNER_USER_ID`:**
- Напишите боту @userinfobot или @getmyid_bot — он пришлёт ваш ID.

### 4. Запуск бота

```bash
python main.py
```

При первом запуске Telethon запросит код подтверждения, отправленный в Telegram. Введите его в консоль — сессия сохранится, и в следующий раз код не потребуется.

## 📱 Использование

После запуска бот готов к работе. Напишите ему `/start` — откроется главное меню:

### 📢 Мои каналы
- Нажмите **➕ Добавить канал** и отправьте ссылку или юзернейм (например, `@design_jobs`).
- Бот проверит, подписаны ли вы на этот канал. Если да — канал будет добавлен и начнёт отслеживаться.
- Для каждого канала можно приостановить/возобновить отслеживание, удалить его или просмотреть найденные вакансии (в разработке).

### 🔎 Мои фильтры
- Нажмите **➕ Новый поиск** и введите запрос на естественном языке.
- Примеры:
  - `UX/UI дизайнер удалённо, без опыта`
  - `Python разработчик, но не джуниор`
  - `Project Manager OR Product Manager, remote`
- Бот автоматически разобьёт запрос на обязательные (AND), желательные (OR) и исключающие (NOT) условия.
- Для каждого фильтра можно включить/выключить паузу или удалить его.

### ⚙️ Настройки (в разработке)
- В будущем здесь будут настройки уведомлений и порогов релевантности.

## 🧠 Как работает обработка вакансий

1. **Обнаружение вакансии** — пост считается вакансией, если содержит ключевые слова (`вакансия`, `ищем`, `требуется`, `hire`, `job` и т.д.) и не содержит стоп-слов (`реклама`, `новости`, `дайджест`).
2. **Извлечение данных** — парсятся:
   - Название должности
   - Компания
   - Зарплата (по шаблонам)
   - Локация
   - Контакты (email, телефон)
   - Навыки (из ограниченного словаря, можно расширять)
3. **Сопоставление с фильтрами**:
   - Обязательные условия должны все совпасть (AND).
   - Исключающие условия не должны встречаться (NOT).
   - Желательные условия повышают рейтинг (OR).
   - Используются синонимы, лемматизация (приведение к нормальной форме), fuzzy-сравнение (порог 85%).
4. **Рейтинг (score)** — вычисляется как процент совпавших условий от общего числа (обязательные + желательные). Уведомления отправляются только при `score >= 75%` (порог настраивается).
5. **Уведомление** — формируется карточка с основной информацией, рейтингом, кнопками для перехода к посту и в канал.

## 🔧 Настройка порога уведомлений

По умолчанию уведомления отправляются при `score >= 75`. Вы можете изменить это значение в `main.py` в функции `post_processor`:

```python
if match_result["matched"] and match_result["score"] >= 75:  # измените 75 на нужное
```

## 🧪 Тестирование

Для проверки работы можно:

1. Добавить тестовый канал, где вы публикуете посты (например, свой канал).
2. Создать фильтр с ключевыми словами, которые точно есть в вашем тестовом посте.
3. Опубликовать пост в канале и проверить, пришло ли уведомление.

При первом запуске Telethon может запросить код подтверждения — введите его в консоли.

## 🐛 Возможные проблемы и их решение

| Проблема | Решение |
|----------|---------|
| Telethon не авторизуется (ошибка `AUTH_KEY_UNREGISTERED`) | Удалите файл сессии (`.session`) и перезапустите бота. |
| Бот не видит каналы, хотя вы подписаны | Проверьте, что в `.env` указан правильный `OWNER_USER_ID` и сессия Telethon принадлежит этому же пользователю. |
| Не приходят уведомления | Проверьте, что фильтр активен, а пост содержит обязательные слова. Посмотрите логи консоли. |
| Ошибка при создании приложения на my.telegram.org | Используйте VPN с IP страны вашего номера, выберите платформу Desktop, описание от 40 символов. |

## 🧩 Расширение функциональности

- **Добавление новых синонимов** — в файле `matching.py` расширьте словарь `SYNONYMS`.
- **Изменение списка навыков** — в `vacancies.py` дополните список `common_skills`.
- **Настройка интервала опроса** — в `telegram_client.py` измените `await asyncio.sleep(30)` на нужное значение (в секундах).
